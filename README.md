# gen-1

Лаборатория эволюционных агентов. Концепция и план: [docs/gen-1-concept.md](docs/gen-1-concept.md).

## Команды

```bash
npm install
npm run dev        # dev-сервер Vite
npm run typecheck  # проверка типов (app / worker / node)
npm test           # тесты Vitest
npm run build      # проверка типов и сборка в dist/
```

## Структура

```text
src/
  app/           # App и запуск
  core/          # ContextSingleton, SeededRandom, конфигурация по умолчанию
  simulation/    # SimulationEngine, World, Organism, Genome, SpatialIndex, системы; без Three.js и DOM
  worker/        # точка входа Worker, SimulationRuntime, SimulationBridge
  rendering/     # SceneManager, WorldRenderer, CameraController
  ui/            # панель управления, инспектор, графики
  shared/        # конфигурация модели, гены, формат снимков, протокол
```

## Управление

- Перетаскивание — перемещение карты, колесо — масштаб.
- Щелчок по организму — инспектор; × в инспекторе снимает выбор.
- По умолчанию самцы синие, самки розовые; режим окраски можно сменить.
- Детёныши растут, растения уменьшаются при поедании и восстанавливаются на прежнем месте.

## Модель жизни, версия 2

У организмов есть энергия, желудок, здоровье и выносливость. Пища усваивается постепенно;
организмы выбирают питание, отдых, исследование и поиск партнёра. Видимость ограничена сектором
и препятствиями, последнее кормовое место сохраняется в памяти на ограниченное время.

Размножение возможно только при встрече зрелых, здоровых и обеспеченных энергией самца и самки.
Самка вынашивает одного детёныша, оба родителя оплачивают спаривание, после него действует
период восстановления. Детёныш наследует каждый признак от одного из родителей с возможной
мутацией; его пол определяется случайно. Родители и потомки, а также особи с общим родителем
не спариваются. Стартовые полы сбалансированы, стартовые организмы взрослые.

Растения имеют конечную биомассу и отрастают с учётом плодородия и сезона. Параметр появления
пищи задаёт появление новых растений до лимита, восстановление существующих задаётся отдельно.
«Начало старения» повышает риск смерти и снижает скорость, а не убивает всех в один возраст.

В инспекторе доступны оба родителя, физиология, беременность и причина текущего действия;
на графиках — оба пола, взрослые особи, беременности и запас растительной пищи.
Сохранения версии 1 несовместимы с версией 2. Истории сравнений разных версий хранятся отдельно.

Параметры модели по умолчанию — `src/core/config.ts`, диапазоны генов — `src/shared/genes.ts`,
шаблоны препятствий и зон — `src/shared/environment.ts`.

## Эксперименты

- **Настройки эксперимента** — seed, стартовые численности, препятствия, зоны ресурсов, сезонность, мутации.
  «Применить» меняет параметры текущего запуска; поля с пометкой «после сброса» (seed, стартовые численности,
  препятствия) вступают в силу через «Применить и сбросить» или «Сброс».
- **Сохранить в файл / Загрузить** — полное состояние (конфигурация, организмы, пища, генератор, история).
  Продолжение из файла совпадает с непрерывным запуском в пределах одной версии модели (`MODEL_VERSION`).
- **Сравнение запусков** — «Добавить текущий запуск» сохраняет историю в браузере (до 8 записей);
  до 3 запусков накладываются на графики численности, пищи, энергии и среднего гена, итоги — в таблице.

Код в `src/simulation` и потока Worker проверяется через `tsconfig.worker.json` без библиотеки DOM. `SimulationBridge` работает в главном потоке.
